# ESP32 Indoor Environmental Monitor / 室内环境监测系统

## 中文

基于 ESP32 和 ESP-IDF 的毕业设计项目，采集温度、相对湿度、光照度和颗粒物浓度。当前仓库包含设备端固件；后续计划通过 Wi-Fi/MQTT 将数据传输至 Android 应用。

### 硬件与接口

当前目标为 ESP32，开发环境为 ESP-IDF v6.1。引脚和通信配置见下方共用表格。SHT31、BH1750 与 OLED 共用一条 100 kHz I²C 总线；PMS5003 使用独立 UART 接收任务，输出**环境颗粒物浓度**，单位 µg/m³。

各模块必须共地，电源电压按具体模块说明确认；OLED 排针顺序为 `GND VCC SCL SDA`，不要将模块 VCC 与芯片内部面板驱动电压混淆。

### 编译与运行

在 VS Code 中用 ESP-IDF 扩展打开本仓库根目录，选择 `esp32` 目标及开发板串口，依次执行 Build、Flash、Monitor。也可在已激活 ESP-IDF v6.1 环境的终端中运行下方命令，将 `COMx` 替换为实际串口。

检查串口中的温度、湿度、光照度及三个 PM 数值是否持续更新；PMS5003 超过 5 秒无有效帧时显示等待状态，OLED 无有效读数时显示 `--`。OLED 检测日志仅表示通信和初始化命令成功，实际六行显示仍需观察屏幕确认。

An ESP32 final-year project built with ESP-IDF to monitor temperature, relative humidity, illuminance and particulate matter. This repository currently contains device firmware. Wi-Fi/MQTT transmission to an Android application is planned.

### Hardware and interfaces

The current target is ESP32 with ESP-IDF v6.1. SHT31, BH1750 and OLED share a 100 kHz I²C bus. PMS5003 uses a separate UART receive task and reports **atmospheric particulate concentrations** in µg/m³.

All modules must share ground. Confirm supply voltages against the specific module documentation. OLED header order: `GND VCC SCL SDA`; the module supply pin is not the IC's internal panel-drive voltage.

### Build and run

Open the repository root in VS Code with the ESP-IDF extension. Select the `esp32` target and board serial port, then run Build, Flash and Monitor. Alternatively, use the commands below in an activated ESP-IDF v6.1 terminal, replacing `COMx` with the actual port.

Check that serial readings continue to update. PMS5003 readings become unavailable after 5 seconds without a valid frame; invalid OLED readings appear as `--`. An OLED detection log confirms communication and command initialization only; verify the six-row display on the physical screen.

## 接口配置 / Interface configuration

| Device | ESP32 connection | Configuration |
| --- | --- | --- |
| SHT31 | SDA GPIO21, SCL GPIO22 | I²C, 0x44/0x45 auto-probe |
| GY-302 / BH1750 | SDA GPIO21, SCL GPIO22 | I²C, 0x23 |
| SSD1315 OLED | SDA GPIO21, SCL GPIO22 | I²C, 0x3C/0x3D auto-probe, 128×64 |
| PMS5003 | Sensor TX → GPIO16 (ESP32 RX); sensor RX ← GPIO17 (ESP32 TX) | UART2, 9600 baud, 8N1 |

## 命令 / Commands

```sh
idf.py build
idf.py -p COMx flash monitor
```

退出串口监视器 / Exit the serial monitor: `Ctrl+]`.

## Wi-Fi HTTP test / Wi-Fi HTTP 测试

在 ESP-IDF 终端中进入 `FYP` 目录，运行 `idf.py menuconfig`，在 `FYP Wi-Fi` 菜单中填写 Wi-Fi SSID 和密码，然后执行 `idf.py build` 和 `idf.py -p COMx flash monitor`。串口日志中的 `Wi-Fi connected, IP address` 就是手机端要填写的 ESP32 IP 地址。接口地址为 `http://<ESP32_IP>/api/sensors`，返回温度、湿度、光照度和 PM1.0/PM2.5/PM10 的 JSON 数据；传感器无有效数据时对应字段为 `null`。

Android 工程位于 `../FYP_Android`。使用 Android Studio 打开该目录，或在该目录运行 `gradlew.bat :app:assembleDebug`。安装生成的 `app/build/outputs/apk/debug/app-debug.apk`，让手机和 ESP32 连接同一个局域网，在 App 中输入串口日志显示的 IP 地址并点击“连接”。
